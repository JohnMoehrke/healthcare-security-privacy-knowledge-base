# PASS Audit:  Ballot Pool is now open

Originally posted: https://healthcaresecprivacy.blogspot.com/2010/08/pass-audit-ballot-pool-is-now-open.html
Published: 2010-08-31T16:54:00Z
Updated: 2010-08-31T16:54:05.663Z
Author: John Moehrke

---

The HL7 Privacy Access and Security Services (PASS) project team is pleased to announce that the result of our efforts to define a **Healthcare Audit service** specification is now ready for membership review.   The PASS project is a joint effort between the HL7 SOA, Security, and CBCC Workgroups and has had the benefit of active participation from members and Co-Chairs of each of those Workgroups.


The ballot pool for the latest specification entitled "**HL7 Version 3 Standard: Privacy, Access and Security Services (PASS) - Audit Services, Release 1**" is now open until **September 20, 2010**.  We'd like to encourage anyone interested to to sign up for the ballot pool and provide support for this work in the form of review and comments.  The HL7 Ballot Desktop can be accessed at:  [http://www.hl7.org/ctl.cfm?action=ballots.home&ballot_cycle_id=521&ballot_voter_id=0](http://www.hl7.org/ctl.cfm?action=ballots.home&ballot_cycle_id=521&ballot_voter_id=0)mailto:ppyette@perimind.com
