# IHE IT Infrastructure Technical Framework Supplements available for Trial Implementation

Originally posted: https://healthcaresecprivacy.blogspot.com/2010/08/ihe-it-infrastructure-technical.html
Published: 2010-08-11T20:02:00Z
Updated: 2010-08-11T20:02:53.798Z
Author: John Moehrke

---

The [IHE IT Infrastructure (ITI)](http://www.ihe.net/Technical_Framework/index.cfm#IT) committee has published the Trial Implementation specifications. This is the version of the supplements that have been through a 30 day public comment, and now are ready for testing at the coming Connectathon. The following supplements are now in Trial Implementation

- [Cross-Enterprise User Assertion - Attribute Extension (XUA++)](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_Suppl_XUA-_Rev1-1_TI_2010-08-10.pdf)

- These updates add three named options: **Role-Based-Access Control**, **Consent/Authorization, Purpose of Use**, and adds **Other Descriptive Attributes**

- [Healthcare Provider Directory (HPD)](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_Suppl_HPD_Rev1-1_TI_2010-08-10.pdf)

- Creates a way to discover and get attributes about both **Individual Providers** and **Organizational Providers**

- [On-Demand Documents](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_Suppl_On_Demand_Documents_Rev1-1_TI_2010-08-10.pdf) -

- This extends XCA/XDS with support for publication of '**on-demand**' documents

- [Sharing Value Sets (SVS)](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_Suppl_SVS_Rev2-1_TI_2010-08-10.pdf) -

- This was enhanced with a new transaction "**Retrieve Multiple Value Sets**"

- [XDS Metadata Update](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_Suppl_XDS_Metadata_Update_Rev1-1_TI_2010-08-10.pdf) - Published 2010-08-10

- New administrative interface to allow for direct manipulation of metadata entries

**Also updated, but still in Trial Implementation (all changes are fixes from experience/connectathon. Previously documented in Change Proposals)**

- [Vol. 1 (ITI TF-1): Integration Profiles](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_TF_Rev7-0_Vol1_FT_2010-08-10.pdf)

- Vol. 2: Transactions - Volume 2 is divided into three separate sub-volumes:

-

- [Vol. 2a (ITI TF-2a):](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_TF_Rev7-0_Vol2a_FT_2010-08-10.pdf) Transactions  ITI-I through ITI-28. These transactions are used in the following  profiles CT, PSA, EUA, PIX, RID, XDS, ATNA, PDQ, PWP, NAV

- [Vol. 2b: (ITI TF-2b)](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_TF_Rev7-0_Vol2b_FT_2010-08-10.pdf): Transactions (cont'd) ITI-29 through ITI-50. These transactions are used in the following profiles PAM, XDM, XUA, XDS

- [Vol. 2x (ITI TF-2x)](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_TF_Rev7-0_Vol2x_FT_2010-08-10.pdf): Appendices A through W and Glossary

- [Vol. 3 (ITI TF-3):](http://www.ihe.net/Technical_Framework/upload/IHE_ITI_TF_Rev7-0_Vol3_FT_2010-08-10.pdf) Contains Section 4 Cross-Transaction Specifications and Section 5 IHE Content Specifications

These volumes provide specification of the following profiles:

- Audit Trail and Node Authentication (ATNA)

- Basic Patient Privacy Consents (BPPC)

- Consistent Time (CT)

- Cross-Enterprise Document Media Interchange (XDM)

- Cross-Enterprise Document Reliable Interchange

- Cross-Enterprise Document Sharing (XDS.b)

- Cross-Enterprise Sharing of Scanned Documents (XDS-SD)

- Cross-Enterprise User Assertion (XUA)

- Enterprise User Authentication (EUA)

- Patient Administration Management (PAM)

- Patient Demographics Query (PDQ)

- Patient Identifier Cross-Referencing (PIX)

- Patient Synchronized Applications (PSA)

- Personnel White Pages (PWP)

- Retrieve Information for Display (RID)
