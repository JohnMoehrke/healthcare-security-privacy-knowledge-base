# IHE releases IUA, HIE-Whitepaper, and html published Technical Framework

Originally posted: https://healthcaresecprivacy.blogspot.com/2020/12/ihe-releases-iua-hie-whitepaper-and.html
Published: 2020-12-03T13:39:00Z
Updated: 2020-12-03T13:39:07.290Z
Author: John Moehrke

---

Big day for me, and the IHE team. I am so pleased at the way the IHE ITI workgroup membership, and IHE support personal, worked on all of this. I would say this is the biggest impacting release that IHE has done since XDS. This is bittersweet as we recently lost the father of XDS, [Bill](http://motorcycleguy.blogspot.com/2020/11/a-moment-of-silence.html)

Today IHE releases three very important products:

- **An update of IUA**, the profile of OAuth that IHE has defined. This is an alternative to SMART-on-FHIR, and not intended to be conflicting. Each cover unique spaces with some overlap.

- **An update to the HIE-Whitepaper**, bringing in the newly build FHIR based profiles. Profiles like MHD, MHDS, mXDE, QEDm, PMIR, SVCM, mCSD, ATNA, and IUA.

- Brand new publication method for the **ITI Technical Framework using html**. This is just the final-text, does not include trial-implementation supplements, although they are included in the publication framework.

These three publications are all using the html publication framework, and they cross-link into the technical framework. see [https://profiles.ihe.net/](https://profiles.ihe.net/). This is the new home for html published works from IHE.

I will be writing more articles pointing out specific things of each of these publications. coming soon, right here, and possibly elsewhere...
