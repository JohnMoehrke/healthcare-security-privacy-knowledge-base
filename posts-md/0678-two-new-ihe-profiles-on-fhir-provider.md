IHE IT Infrastructure Technical Framework Supplements Published for Public Comment
The IHE IT Infrastructure Technical Committee has published the following supplements to the IHE IT Infrastructure Technical Framework for public comment in the period from **May 17 through June 16, 2017**:

- Mobile Care Services Discovery (mCSD)

- Non-patient File Sharing (NPFS)

The documents are available for download at [http://ihe.net/Public_Comment](http://ihe.us1.list-manage.com/track/click?u=a75e449ea24da34a9a89ed37a&id=9a32f3eadc&e=f71f998cbe). Comments submitted by **June 16, 2017** will be considered by the IHE IT Infrastructure Technical Committee in developing the trial implementation version of the supplements. Comments can be submitted at [IT Infrastructure Public Comments](http://ihe.us1.list-manage.com/track/click?u=a75e449ea24da34a9a89ed37a&id=d80c29658d&e=f71f998cbe).
