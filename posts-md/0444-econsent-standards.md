As with any standard, one more is clearly needed.

https://imgs.xkcd.com/comics/standards.png

as to the different Consent Standards.. I likely don't know about all of them, but here are some. I am also not indicating that there should be no improvement or even new standards. I just don't want historic lessons-learned to be lost.

for use in Document Sharing exchanges like [XDS/XCA/XDR/XDM/MHD/MHDS](https://profiles.ihe.net/ITI/HIE-Whitepaper/index.html)

- IHE - Basic Patient Privacy Consent - [https://profiles.ihe.net/ITI/TF/Volume1/ch-19.html](https://profiles.ihe.net/ITI/TF/Volume1/ch-19.html)
- IHE - Advanced Patient Privacy Consent - [https://profiles.ihe.net/ITI/TF/Volume1/ch-43.html](https://profiles.ihe.net/ITI/TF/Volume1/ch-43.html)

This fall I hope to get a FHIR Consent - basic patient privacy project going.

There is an orchestration of various things referred to as Point-of-Care, which is an interaction model using BPPC and XUA - [https://healthcaresecprivacy.blogspot.com/2017/01/enabling-point-of-care-consent.html](https://healthcaresecprivacy.blogspot.com/2017/01/enabling-point-of-care-consent.html)
- this is part of CareQuality, and is built into Epic's CareEverywhere

The FHIR Consent - [http://hl7.org/fhir/consent.html](http://hl7.org/fhir/consent.html) FHIR Consent is rich to be profiled.

There are some projects that claim to be profiling Consent, but they are not yet published.

There is work in FHIR to add a Permission Resource. This would possibly be used by Consent in the future, but that future is likely 5 years out - [http://build.fhir.org/permission.html](http://build.fhir.org/permission.html)

There is also the OpenID - UMA - HEART - [https://openid.net/wg/heart/](https://openid.net/wg/heart/)

There is a broader (beyond healthcare) project in Kantara to support a Consent Receipt
 -- [https://healthcaresecprivacy.blogspot.com/2018/03/fhir-consent-resource-mapping-to.html](https://healthcaresecprivacy.blogspot.com/2018/03/fhir-consent-resource-mapping-to.html)

surely I missed something? Please comment or email me.
